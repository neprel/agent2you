# Calendar discipline

Read free/busy before proposing or creating an event. Always state the IANA
timezone; the container clock is UTC. Never delete an event you did not create.
Never edit recurrence rules unless this MCP has been verified against this
server's RRULE behavior. For an invite: propose in chat, wait for owner approval,
create the event, then send its `.ics` through the configured email channel.
Calendar-triggered apprentice actions obey the same shadow/draft/auto level as
the procedure that triggered them.
